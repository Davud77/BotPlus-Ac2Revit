# BotPlus Ac2Revit

**BotPlus Ac2Revit — универсальный транслятор BIM-моделей из Archicad (PLN) в Autodesk Revit (RVT), находящийся в разработке.**

Наша цель — переносить произвольные проекты максимально полно и быстро, сохраняя геометрию, положение, структуру, свойства, материалы и взаимосвязи элементов. Результат должен быть максимально близок к исходной модели и по возможности состоять из нативных, параметрически редактируемых элементов Revit.

Транслятор получает данные из открытого PLN через Archicad API и Tapir, дополняет их фактической геометрией IFC и собирает RVT через Revit API. Промежуточный JSON-контракт связывает исходные GUID, параметры, зависимости и результаты проверки. Программа рассчитана на входные данные текущего проекта; заранее подготовленные модели для работы не требуются.

## Принципы переноса

- **Точность:** координаты, размеры, единицы и преобразования вычисляются детерминированно.
- **Полнота:** каждый исходный элемент учитывается в отчёте; пропуски и ограничения имеют явную причину.
- **Редактируемость:** приоритет у нативных элементов и семейств с проверенными параметрами.
- **Сохранность формы:** если нативный адаптер ещё не поддерживает элемент, доступная геометрия может передаваться как DirectShape с отметкой об ограничениях.
- **Производительность:** пакетная обработка, повторное использование подготовленных данных и сохранение контрольных точек.

Универсальность — назначение и направление разработки, а не утверждение о стопроцентном переносе всех типов элементов уже сейчас. Актуальные возможности и оставшиеся задачи описаны в [плане развития](docs/ROADMAP.md).

## Как пользоваться

1. [Соберите и подключите плагин](INSTALL.md).
2. Откройте исходный PLN в Archicad с Tapir и запустите Revit.
3. На вкладке **BotPlus Ac2Revit** выберите экспорт и сборку модели.
4. Укажите параметры обмена и шаблон Revit. После сборки сохраните RVT и изучите отчёт о переносе.

Текущая целевая среда: Windows, Revit 2026, Archicad с Tapir 1.7.0. Чтение PLN выполняет установленный Archicad. Растровые текстуры/UV и синхронизация изменённого исходника поверх готовой модели пока требуют отдельных адаптеров.
