# Перенос штриховок через сопоставление

Дата: 16.10.2026. Этап относится к **графике среза материалов** на планах и разрезах. Изображения текстур 3D, отдельные 2D заливки чертежей, фасадные узоры и покраска граней — отдельные последующие адаптеры.

## Данные и сопоставление

Из открытого исходного PLN Абакана прочитаны 423 штриховки Tapir `GetFills`, включая тип, масштабирование, шаги/углы, lineItems, линии/дуги символов; сохранены исходные GUID. Прочитана 21 таблица перьев; выбрана единственная активная для модели — `01 Архитектурный М 1:100`. Проверены назначения среза всех 865 строительных материалов относительно замороженного манифеста: изменений нет. Геометрия актуального PLN этим чтением не синхронизируется.

Из фактического проекта Revit прочитаны 196 FillPatternElement. Каталог содержит вид Drafting/Model, Solid, ориентацию, сетки, шаги, смещения и штрихи. Назначение среза разрешает только **Drafting**: это требование [Revit API Material.CutForegroundPatternId](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-API-MainReference/files/html/9f03bba4-bdb1-5a2e-065e-c1d6ac04bb95.htm).

Новые произвольные рисунки не создаются. Правила в `config/hatch-analogues.ru.json` разрешают конкретный существующий образец ADSK-шаблона. Подготовленный план хранит исходный GUID материала и штриховки, индекс/имя, точное имя цели и отпечаток её реальной геометрии. Одноимённый изменённый образец не принимается; неоднозначное имя блокируется. Все замены рисунка имеют статус **analogue**, а не «точная копия».

| Блоки Бетонные Эффективные | ADSK_Линия_Диагональ_Вверх_2 мм | У источника шаг 1,8 мм; выбран близкий существующий |

Рисунок выбирается по исходной штриховке, а не по названию материала. Например, исходная фиброплита со штриховкой «Фанера 01» сохранит соответствующий древесный аналог; материал не объявляется древесиной.

Подготовлено 749 назначений из 865: **574 аналога, 173 пустых, 2 исходных сплошных заливки 100%**. Все **69 импортированных материалов**, используемые многослойными типами текущего RVT, покрыты. Для 116 материалов без явного аналога назначения не меняются: они записаны как `unmapped` в CSV. Это не доказательство отсутствия этих материалов в каждой иной категории или будущем проекте.

## Цвет, фон, масштаб

RGB переднего пера взят из активной таблицы Archicad, а не заменён общим чёрным. Положительные фоновые перья сохраняются отдельной сплошной фоновой заливкой и исходным RGB. Прозрачный фон остаётся прозрачным; специальный фон окна Archicad `-1` сопоставлен прозрачному фону листа Revit с явной записью ограничения. При другой таблице перьев исходного вида цвета могут отличаться.

25/50/75-процентные заливки не превращаются в чёрную сплошную. Только подтверждённый исходный `Solid` с `percent=1` получает Solid Fill. Пустой материал очищает foreground pattern. Чернота очень тонких слоёв на мелком масштабе, графика категорий/видов и DirectShape без назначенных материалов этим автоматически не исправляются.

Масштаб, фазировка рисунка и `FitToSkin`/`ElementOrigin` Archicad не заявлены эквивалентными Revit. На данном этапе используются Drafting-аналоги из шаблона; исходные параметры ориентации сохранены в плане для следующей доработки.

## Код и порядок

- `tools/export_hatch_catalog.py` — чтение Fill и PenTable, проверка исходных назначений. Поддерживает отдельный экспорт каталога другого PLN без утверждения о переносе его геометрии.
- `tools/prepare_hatch_mapping.py` — строгая подготовка по явным правилам; отказ при непокрытом материале многослойного типа, неверной таблице перьев или неподходящем образце.
- `revit/Ac2Revit/HatchMappingStage.cs` — изменение только графики импортированных материалов, транзакционная проверка и чтение результата.
- `PipelineRunner` — этап после ресурсов и перед импортом конструкций, затем повторный аудит в конце сценария.

Сопоставление работает только с материалами, принадлежащими этому проекту по ExtensibleStorage. Материалы пользователя вне этого индекса не меняются. Контроль последнего назначенного состояния хранится в DataStorage: повторный запуск распознаёт ручное изменение графики и отказывается молча его перезаписать. Изменение самих правил допускается, если исходное состояние Revit не редактировали посторонним способом.

Обычная кнопка «Импорт JSON»: `artifacts/pipeline/abakan-hatches-20261016/pipeline.json`. План сопоставления: `artifacts/hatches/abakan-20261016/hatch-mapping.json`, подробная таблица: `mapping-inventory.csv`. Для другого шаблона следует прочитать его каталог и заново разрешить цели: ADSK-имена не обещаются в стандартном шаблоне Autodesk.
