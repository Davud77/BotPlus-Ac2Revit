# Работа из интерфейса Revit

Вкладка **BotPlus Ac2Revit** объединяет экспорт из открытого Archicad и сборку модели Revit. Установка описана в [INSTALL.md](../INSTALL.md).

| Кнопка | Назначение |
|---|---|
| Archicad → Revit | Прочитать текущий PLN, экспортировать JSON/IFC, подготовить этапы и собрать RVT |
| Экспорт Archicad | Подготовить обмен без построения модели |
| Продолжить сеанс | Восстановить завершённое чтение из архивов и продолжить подготовку; готовый IFC используется повторно |
| Собрать экспорт | Собрать последний успешно подготовленный сеанс |
| Проверить JSON | Проверить выбранный manifest.json или pipeline.json |
| Импорт JSON | Импортировать подготовленный файл в открытый проект Revit |
| Папка обмена | Открыть сеансы и отчёты |

## Обычный запуск

1. Сохраните исходный PLN и откройте его в Archicad с Tapir. Дождитесь завершения загрузки.
2. Запустите Revit и откройте вкладку **BotPlus Ac2Revit**. Экспорт и мастер доступны без заранее созданного проекта Revit.
3. Нажмите **Archicad → Revit**. Проверьте источник, порт и переводчик IFC из списка текущего PLN.
4. Выберите новый проект Revit или явно укажите текущий. Выберите RTE: его каталог материалов и штриховок влияет на доступные аналоги.
5. Запустите экспорт. До завершения чтения не изменяйте и не переключайте исходный проект.
6. Перед построением выберите категории в окне **Что переносить**. Оно показывает количества исходных записей и автоматически включаемые зависимости. Двери/окна включают стены, самостоятельные проёмы — фактические категории своих хостов, помещения — конструкции и проёмы для границ. Не выбранные категории не создаются и не считаются потерями импорта; ранее созданные элементы не удаляются.
7. Дождитесь окончания, сохраните RVT и проверьте отчёты. Обозначения неполноценного переноса требуют отдельного внимания.

Tapir вызывается через `API.ExecuteAddOnCommand` / `TapirCommand` по `127.0.0.1`, порт по умолчанию `19723`. Плагин не читает бинарный PLN самостоятельно: доступ к данным предоставляет установленный Archicad.

## Данные обмена

Читаются этажи, GUID и подробности элементов, привязки/связи, конструкции, строительные материалы, поверхности, профили, штриховки, перья, классификации и доступные свойства. Полные GDL-параметры включаются отдельно и могут значительно увеличить архив. Они не обязательны для получения IFC-тел.

JSON и контрольные суммы записываются потоком. Большие GDL сохраняются в `source/raw`; `gdlReference` содержит относительный путь, JSON Pointer, размер и SHA-256. Передавайте сеанс вместе с этими файлами.

IFC дополняет фактическую геометрию и оси. Соответствие определяется исходными GUID/явными IFC ID. Преобразование координат проверяется по точным соответствиям; непроверенное смещение не применяется. Полный порядок сборки описан в [плане развития](ROADMAP.md).

## Шаблон и оформление

Оси получают исходные видимые подписи. Для повторов Revit использует невидимый символ, а исходные GUID остаются в данных элемента. Видимые суффиксы с IFC ID не добавляются.

Семейства `AC2R_OpeningVoid` и режущие экземпляры балок выполняют нативное вычитание геометрии. Они закрепляются, получают поясняющий комментарий и скрываются в существующих планах/3D/разрезах. Скрываются только собственные служебные вырезы, а не вся категория «Обобщённые модели». Удаление выреза восстанавливает материал хоста; скрытие выреза сохраняет отверстие. Новые вручную созданные виды могут потребовать повторного применения оформления.

Штриховки сопоставляются по `config/hatch-analogues.ru.json` с реально существующими Drafting-образцами выбранного шаблона. Отсутствующие цели отражаются как `unmapped`. Назначение цвета/штриховки не означает перенос растровой текстуры или UV.

## Остановка и продолжение

Остановка локального обработчика не гарантирует немедленную отмену уже отправленной операции Archicad. Незавершённый сеанс не публикуется как готовый экспорт. Продолжение проверяет источник и завершённость чтения; повреждённый IFC не перезаписывается автоматически.

Если большой IFC не помещается в доступную память вместе с открытым Archicad, мастер сохраняет проверенный захват и предлагает **Продолжить подготовку**. Закройте Archicad и ненужные модели Revit, затем продолжите в том же окне или через **Продолжить сеанс**. При наличии `capture.json` подключение к Archicad не требуется: сначала сверяются контрольные суммы всех входных файлов. Предыдущий готовый экспорт остаётся выбранным для сборки до успешного завершения новой подготовки.

Выбранный шаблон сохраняется и для отложенной подготовки. При повторном открытии сеанса восстанавливается тот же путь; пустой выбор означает метрический проект. Если сохранённый шаблон исчез, мастер просит исправить путь перед сборкой.

Сохраняемые этапы ограничивают потерю работы. Контрольные точки помещений содержат курсор и результаты; завершённые пакеты сохраняются до переоткрытия RVT. Подробности конфликтов и повторов — в [описании поведения импорта](IMPORT-BEHAVIOR.md), приёмка — в [документе проверок](VALIDATION.md).
