## Что означает пометка

Подсчёт всех стен не означает полную геометрическую приёмку. Независимая сверка добавленных стен после соединений дала:

- 8 сеточных замен прошли сравнение с IFC.
- 111 нативных стен отличаются от IFC по конечной форме/объёму. В выборке расхождение поверхности достигает **390 мм**; основной видимый пример — различная протяжённость торцов/слоёв в узле. Привязка, тип, толщина и номинальная ось сами по себе не описывают такую net-геометрию.
- 1 новая нативная стена (`16D3BD85-1BA1-411E-A262-81241D75EFE8`) не имеет однозначного соответствия по GUID в IFC. Она построена по API-параметрам; независимая форма не подтверждена.

Поэтому **все 120 добавленных стен** помечены: 8 геометрических замен, 111 с непройденной сверкой формы и 1 без IFC-эталона. Среди 111 отдельно указана ограниченная семантика Core трёх стен. Нативные стены сохранены как редактируемые элементы; они не выдаются за полностью принятый результат. Полная независимая приёмка остальных 6869 стен также остаётся отдельной задачей.

В Revit искать по параметру **«Комментарии» → содержит «НЕПОЛНОЦЕННАЯ СТЕНА»**. У 8 DirectShape пометка есть также в имени.

## Помещения: что изменилось после восстановления стен

До этого этапа: 221 принято, 301 выше допуска, 31 незамкнутое. Теперь: **231 принято, 321 выше допуска, 1 незамкнутое**. Тридцать областей стали замыкаться; из них десять прошли допуск, двадцать всё ещё имеют другую площадь. Допуск остался 1 м².

Во всех 321 превышениях площадь Revit больше исходной. Медиана превышения — 17,2845 м², максимум — 131,0745 м². Сравнивается геометрическая площадь исходного полигона с отверстиями, а не расчётная площадь Archicad с коэффициентами.

В Revit исследованы двадцать крупнейших отклонённых зон **по исходной площади**. Для каждой пробно создавался Room, читались Finish/Center/CoreBoundary/CoreCenter, реальные ограничивающие элементы и сечения колонн. Все эти пробные транзакции откатились. ### Автостоянка: конкретный разрыв

Её исходный контур содержит отрезок:

`(28.407689703, 74.682864336) → (24.277413752, 74.682864336)`, длина **4,130276 м**.

Под этим участком на расчётной высоте нет исходной стены. Рядом находятся объекты **«Пандус Прямой 27»**. В исходной выгрузке нет категории 2D Line/Polyline, поэтому происхождение исходной разделяющей линии ещё нужно подтвердить экспортом 2D границ зон.

В тестовой копии добавлена только линия разделения по этому точному участку исходного контура. Автостоянка сразу стала замкнутой, площадь **3338,212735 м²**. Это подтверждает причину незамкнутости, но **не приёмку площади**: превышение 21,888529 м² остаётся. В исходной зоне 74 отверстия суммарно 21,152250 м²; требуется сопоставить их с колоннами/отделкой, а оставшуюся разницу — с наружной границей.

Основная модель не содержит эту пробную линию и принудительно созданную автостоянку. Тестовая копия: `artifacts/stages/room-column-behavior-probe-20261015/Column_behavior_probe.rvt`.

### Колонны: геометрия есть, но Room Bounding не перенесён полностью

У части профильных семейств параметр «Материал для поведения модели» равен **«Прочее»**; параметра экземпляра «Граница помещения» нет. В тестовой копии смена поведения семейства `AC2R_Profile_4c67d1f0a58a92542f78` на «Бетон» сделала Room Bounding доступным и уменьшила площадь БКТ 4 с **158,698720 до 157,533502 м²**. Остаток относительно исходной площади — 2,193868 м².

Для БКТ 3 исследована стена `4714B1BB-0715-418B-BF51-0631DB490EC0`. Она реально присутствует и ограничивает исходный Room с обеих сторон: область обходит её конец через колонну. У концов находятся колонны `7742957F-C372-4486-9705-90AF20FB12C7` и `6AE35BE0-0FAD-4656-B2CD-03F844F79445` без доступного Room Bounding.

После изменения поведения двух соответствующих семейств в отдельной копии БКТ 3 уменьшился **138,210913 → 122,119215 м²**, остаток 1,608540 м². БКТ 2 уменьшился только **137,952416 → 136,649418 м²**: испытанных семейств недостаточно для этого помещения. Изменение расчётной высоты уровня 0 → 1 м до смены поведения не меняло площади этих двух помещений, поэтому эта гипотеза для них не подтвердилась.

Материал подтверждён через исходные Core skins профилей: GUID `69D6F3CF-6474-4FC2-9EC5-7AD6EB936C65`, имя **«Железобетон - Конструкционный»**. Для 80 загруженных профильных семейств подготовлено однозначное соответствие этому материалу. Ещё 3 семейства имеют изоляционный материал и требуют отдельного решения; назначать им бетон ради Room Bounding нельзя.

Соответствие — `artifacts/quality/rooms-largest-20261015/column-behavior-source-mapping.json`. На основную модель оно ещё не применено: бетонное поведение включает дополнительные взаимодействия конструкций. Даже возврат параметра к «Прочее» в первой тестовой копии не вернул прежнюю площадь после пересоздания Room; нужно проверить устойчивые изменения соединений/границ, а не считать такую операцию полным откатом.

Ограничения поведения описаны также в [документации Autodesk по семействам несущих колонн](https://help.autodesk.com/cloudhelp/2022/ENU/Revit-StructEng/files/GUID-14405018-2947-4E3B-B5CA-4CD500C0A71D.htm). Проверка здесь опирается на фактические свойства модели и эксперимент, а не на имя семейства.

## Реализация и проверки

`Importer` больше не блокирует тип только из-за отсутствия Core: проверяет допустимость Revit CompoundStructure, функции и толщины после назначения. `WallCompletion` выполняется после нативных стен, сначала использует IFC-тело, при его отсутствии допускает явно помеченную номинальную призму; затем проверяет покрытие всех исходных GUID и останавливает сценарий при оставшемся пропуске. **В данном результате номинальные призмы не понадобились.**

Обычная кнопка использует тот же PipelineRunner. В подготовленном пакете IFC-тела есть для 119 из первоначально проблемных 120 стен; последняя успешно создана нативно. Файл IFC проверяется по SHA256. Для других моделей пакет тел нужно подготовить заново.

В Revit выполнен полный запуск **v24** (218,23 с), независимо прочитаны все 6989 стен; 112 нативным ограничения дописаны через проверенные preview/apply Revit API, модель сохранена. Расширенная автоматическая пометка всех no-Core стен, сохранение пользовательских комментариев и типов собраны в **v25** и зарегистрированы для следующего запуска Revit. v25 собран без предупреждений и ошибок; отдельный полный запуск этой версии ещё не выполнен. Текущий процесс продолжает использовать v24. 30 Python-тестов прошли.

Обратное чтение всех стен и маркировок подтверждает 6989 уникальных исходных GUID, 0 пропусков/лишних, 6981 Wall, 8 DirectShape, 120 отмеченных ограничений. Итоговый граф сопряжений и точная форма всех остальных стен остаются отдельной приёмкой.

Повторный независимый аудит после добавления стен: все 61 ось проверены, 1775 нативных вырезов подтверждены, прежние 8 пустых вырезов отсутствуют; новых ошибок этого аудита нет. Результат: `artifacts/reference-exchange/pipeline-audit-20261015-140404/audit.json` (5,53 с).
