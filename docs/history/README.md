# Архив технических отчётов

Здесь хранятся обезличенные отчёты прежних версий: результаты отдельных прогонов, исследование геометрии, ошибки и принятые исправления. Счётчики описывают конкретный прогон и не определяют пределы универсального транслятора. Команды старых версий могут отличаться от действующего CLI; локальные BIM-файлы и архивы не опубликованы.

Текущие инструкции: [установка](../../INSTALL.md), [интерфейс](../REVIT-EXCHANGE-INTERFACE.md), [план развития](../ROADMAP.md), [проверки](../VALIDATION.md). Обзор изменений — в [истории разработки](../DEVELOPMENT-HISTORY.md).
