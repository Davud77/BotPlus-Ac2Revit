## Основные папки

| Папка | Что хранится |
|---|---|
| `Исходники` | Три оригинальных PLN пользователя; не изменяются скриптами |
| `revit`, `exporter`, `tools`, `tests` | Исходный код плагина, выгрузки, подготовщики и тесты |
| `config` | Правила сопоставления и реестр тестовых проектов |
| `contracts` | Контракты JSON |
| `docs` | Порядок работы, проверенные результаты и ограничения |
| `dist` | Актуальная сборка и сохранённые контрольные версии |
| `artifacts/pipeline` | Сценарии для обычной кнопки «Импорт JSON» |
| `artifacts/hatches` | Каталоги штриховок двух программ, таблица сопоставления, результаты проверки |
| `artifacts/quality` | JSON/CSV/HTML доказательства качества и разбор оставшихся проблем |
| `artifacts/reference-exchange` | Исходный IFC и независимые чтения геометрии Revit |
| `artifacts/abakan-v1`, `artifacts/room-separators` | Исходные ответы API и снимки, необходимые для воспроизведения |
| `research/tapir-source-1.7` | Единственная сохранённая копия исходников Tapir |
| `.ifc-env`, `.build-runtime` | Рабочие зависимости Python/.NET; нужны для запуска и сборки |

Промежуточные модели из старых документов удалены по просьбе пользователя; их JSON/CSV отчёты оставлены. Ссылки на старые удалённые RVT в исторических записях не означают, что это актуальные результаты.
